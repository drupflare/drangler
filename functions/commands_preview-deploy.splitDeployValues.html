      Splits the values the duplicate needs into vars and secrets.

      A Worker cannot hold a var and a secret under one name (Binding name 'PLAN' already in use, code 10053), and the workspace's wrangler.jsonc declares PLAN among its vars. Locally .dev.vars overrides a var, so the whole set is written there; a deploy has to send the declared names as --var and only the rest as secrets. Found 2026-10-16 when secret bulk refused the file after the worker was already up.

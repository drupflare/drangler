    Interface SetupOptions

    The three setup/* owner routes, which had no CLI at all.

    /setup/cf, /setup/mail and /setup/oidc are owner-gated and documented, and /setup/mail had neither a command here nor a control in the admin surface -- 45 KB of mail onboarding reachable only by hand-crafting a request with a bearer token.

    Each is a READ by default and a write only when asked, because every one of them is something an operator wants to look at more often than change.
